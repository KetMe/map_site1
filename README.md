# Карты городов с аудио-точками

Минималистичный черно-белый сайт с картами Верещагино (Пермский край) и Москвы. При клике на точки на картах воспроизводится аудио-семпл. цоу

## Структура проекта

```
maps-site-backup/
├── index.html          # Основная HTML страница
├── styles.css          # Стили (черно-белый минималистичный дизайн)
├── script.js           # JavaScript для карт и аудио
├── audio/              # Папка с аудио файлами
└── README.md           # Этот файл
```

## Установка и запуск

1. Поместите ваши аудио файлы (формат MP3, WAV, OGG) в папку `audio`
2. Откройте `index.html` в браузере или используйте локальный сервер:

   ```powershell
   # Python 3
   python -m http.server 8000
   
   # Затем откройте http://localhost:8000 в браузере
   ```

## Настройка точек на картах

Откройте файл `script.js` и измените:

1. **Координаты точек**: Измените значения `lat` (широта) и `lng` (долгота) для каждой точки
2. **Пути к аудио файлам**: Измените пути в параметре `audioPath` (например, `'audio/your_file.mp3'`)
3. **Названия точек**: Измените параметр `title` для подсказок при наведении
4. **Количество точек**: Добавьте или удалите вызовы функции `createAudioMarker()`

## Формат аудио файлов

Поддерживаются следующие форматы:
- MP3 (рекомендуется)
- WAV
- OGG

## Технологии

- **Leaflet** - библиотека для интерактивных карт
- **OpenStreetMap** - картографические данные
- **HTML5 Audio API** - воспроизведение аудио

## Особенности дизайна

- Минималистичный черно-белый стиль
- Чистая типографика с увеличенными межбуквенными интервалами
- Черные границы и акценты
- Градации серого для карт
- Адаптивный дизайн для всех устройств

## Примечания

- Для работы карт необходимо интернет-соединение (загрузка тайлов OpenStreetMap)
- Аудио файлы должны находиться в папке `audio/` с расширением .ogg
- Координаты можно найти через сервисы вроде Google Maps или Яндекс.Карты
