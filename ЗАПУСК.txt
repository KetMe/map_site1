1. ДОБАВЬТЕ АУДИО ФАЙЛЫ:
   - Откройте папку "audio"
   - Поместите туда ваши аудио файлы в формате OGG
   - Назовите их: vereshchagino_sample1.ogg, vereshchagino_sample2.ogg,
     moscow_sample1.ogg, moscow_sample2.ogg, moscow_sample3.ogg
   - Или измените пути в script.js

2. ОТКРОЙТЕ САЙТ:
   - Дважды кликните на файл "index.html"
   - ИЛИ откройте через браузер: File > Open > index.html

3. ЕСЛИ НУЖЕН ЛОКАЛЬНЫЙ СЕРВЕР:
   - Откройте PowerShell в этой папке
   - Выполните: python -m http.server 8000
   - Откройте в браузере: http://localhost:8000

4. НАСТРОЙКА ТОЧЕК:
   - Откройте файл "script.js"
   - Измените координаты (lat, lng) для точек
   - Измените пути к аудио файлам
   - Добавьте или удалите точки
